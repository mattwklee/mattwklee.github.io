Sponsors include NSF (CAREER), DOE ARPA-E (IGNIITE), DOE VTO, USDA NRCS, US Army DEVCOM GVSC, NASA, the SCMC Hub, and industry partners including BorgWarner, Hyundai Motors, and General Motors.

<div class="topic-panel is-active" id="t1">
  <h3>Neutral-Point-Less (NPL) Multilevel Inverters</h3>
    <p>Our NPL inverter family (H-type and X-type) achieves three-level operation with a single DC-link capacitor, eliminating the neutral point entirely - improving efficiency and power quality without split-capacitor balancing.</p>

      gb.classList.add('is-active');
      var firstVisible = null;
      tbtns.forEach(function (tb) {
        var show = (g === 'all' || tb.getAttribute('data-group') === g);
        tb.style.display = show ? '' : 'none';
        if (show && !firstVisible) { firstVisible = tb; }
      });
      var active = document.querySelector('.topic-btn.is-active');
      if (active && active.style.display === 'none' && firstVisible) { firstVisible.click(); }
    });
  });
